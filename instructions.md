## Custom box flow
1. user clicks "create a custom box"
2. user is redirected to /custom-box
3. Type of box (stationary, utility, pooja, mixed, etc) and theme (birthday, anniversary, diwali, etc)
4. user can add products to the box
5. user can remove products from the box
6. user can change the quantity of products in the box
7. user can checkout with the box
